# ریپوی محتوای بلاگ (نیک‌نگار)

کار زمان‌بندی‌شده‌ی Claude مقاله‌ها را این‌جا می‌نویسد و سرور سایت از این‌جا برمی‌دارد.

| فایل | نقش |
|---|---|
| `prompts/article-guide.md` | قواعد نوشتن. **بخش ۱ را برای این سایت پر کن.** |
| `prompts/daily-task.md` | دستور کار روزانه و حالت دکمه‌ی «مقاله‌ی جدید» |
| `site/profile.json` | زبان‌ها، لینک دعوت به اقدام، تعداد کلمه |
| `site/links.json` | صفحه‌هایی که مقاله می‌تواند به آن‌ها لینک بدهد |
| `site/articles.json` | فهرست مقاله‌های نوشته‌شده؛ نویسنده خودش پر می‌کند |
| `topics.json` | صف کلمات کلیدی؛ ترتیب فایل همان اولویت است و از پنل تلگرام هم ویرایش می‌شود |
| `requests.json` | شمارنده‌ی دکمه‌ی «مقاله‌ی جدید»؛ فقط سرور تغییرش می‌دهد |
| `drafts/` | پیش‌نویس‌ها |
| `tools/check.py` | چک کیفیت هر پیش‌نویس: `python3 tools/check.py drafts/<file>.json` |
